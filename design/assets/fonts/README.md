# Typefesse

Typefesse Claire-Obscure and Typefesse Pleine by Océane Juvin, published by
Velvetyne Type Foundry under the SIL Open Font License. Downloaded from
velvetyne.fr/fonts/typefesse. These are the woff2 web cuts; production should
vendor the full release (including the OFL licence file) from the source
repository. The typeface is the illustration layer of Mio's book (see the
book's colophon) and of the site.
